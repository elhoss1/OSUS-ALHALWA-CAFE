# استقبال طلبات عرض السعر في ووردبريس

الملف `osus-quote-requests.php` يضيف عنصر **طلبات التوريد** إلى لوحة التحكم، ويحفظ بيانات المنشأة والتواصل والأصناف والكميات وخيارات الحجم والملاحظات. كما يرتب القائمة الجانبية بحيث تكون **الرئيسية أولًا، المنتجات ثانيًا، وطلبات التوريد ثالثًا**.

## مهم: تحديث الـSnippet الموجود

المسار الحالي على WordPress يرجع `rest_no_route`، ما يدل أن كود الاستقبال لا يعمل على الموقع الآن. لا تنشئ نسخة ثانية فعّالة من الكود القديم والجديد معًا.

1. من لوحة WordPress افتح **Snippets → All Snippets**.
2. ابحث عن Snippet «طلبات توريد ميني أسس» أو «طلبات عرض السعر». عطّله أولًا، ثم افتحه واستبدل محتواه كاملًا بالكود الموجود في `osus-quote-requests.php`. إذا لا يوجد، أنشئ Snippet جديدًا.
3. احذف سطر `<?php` الأول عند اللصق فقط إذا كان محرر Code Snippets يضيفه تلقائيًا.
4. فعّل الكود على **Run snippet everywhere**، واحفظ التغييرات.
5. حدّث لوحة التحكم. يُفترض أن تظهر «المنتجات» مباشرة بعد «الرئيسية»، ثم «طلبات التوريد» بعدها.

## اختبار التفعيل

افتح هذا العنوان بعد تفعيل الكود:

`https://osus-alhalwa.com/backend/wp-json/osus/v1/quotes`

النتيجة الصحيحة JSON يحتوي `"active":true`. إذا ظهر 404 أو `rest_no_route`، لم يُفعّل الكود على نسخة WordPress الصحيحة أو منعه خطأ/كاش. امسح كاش WordPress/LiteSpeed وجرب مرة أخرى. لا ترسل طلبًا حقيقيًا قبل نجاح الفحص.

إذا كان Snippet مفعلًا لكن لا تظهر القائمة، تحقق أن دور حسابك يملك صلاحية إدارة المحتوى، وتأكد من عدم وجود خطأ في سجل PHP أو شاشة Code Snippets.

الـSnippet يسجل الطلبات في لوحة WordPress فقط؛ لا يرسل بريدًا أو واتساب تلقائيًا.
